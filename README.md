# 🔐 SecureVault

SecureVault is a secure offline multi-factor authentication (MFA) system developed using Python, PyQt5, and SQLite. The project provides multiple layers of authentication including password verification, graphical passwords, locally generated OTPs, and recovery phrases to enhance database and user security.

The application is designed for environments where internet access is limited or unavailable, making it a reliable and secure offline authentication solution.


# 🌟 Features

- 🔐 Multi-Factor Authentication (MFA)
- 🔑 Password-Based Login
- 🖼️ Graphical Password Verification
- 📲 Offline TOTP (Time-Based OTP)
- 🛡️ Account Lockout Protection
- 🔄 Recovery Phrase Mechanism
- 📁 Secure Personal Vault
- 💾 SQLite Database Integration
- 🖥️ User-Friendly PyQt5 GUI
- 🌐 Fully Offline System


# 📌 Project Overview

Traditional authentication systems mostly depend on passwords or internet-based OTP verification, which can be vulnerable or inaccessible in offline environments. SecureVault solves this issue by combining multiple authentication layers into a completely offline system.

The project ensures that even if one authentication method is compromised, additional layers continue protecting user data and database access.


# 🛠️ Technologies Used

| Technology | Purpose |
|------------|----------|
| Python 3 | Core development |
| PyQt5 | GUI development |
| SQLite3 | Local database |
| pyotp | OTP generation |
| qrcode | QR code generation |
| Pillow | Image handling |


# 🔐 Authentication Layers

SecureVault uses multiple verification methods:

1. Username & Password
2. Graphical Password
3. Offline TOTP Verification
4. Recovery Phrase

These layers significantly improve security against:
- Brute-force attacks
- Password theft
- Unauthorized access
- Shoulder surfing attacks
